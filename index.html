📱 मेरा पहला Smartphone

पहला फोन मिला? पहले यह करें!

नया smartphone मिलने पर सबसे पहले ये 5 काम करें — अपनी सुरक्षा के लिए।

01
🔒
Screen Lock लगाएं
Settings → Security → Screen Lock → PIN या Pattern चुनें। कम से कम 6 अंकों का PIN रखें।
⚠️ कभी भी 1234 या अपनी जन्म तारीख PIN मत रखें
02
🔄
Software Update करें
Settings → Software Update → Download and Install। पुराने software में hackers आसानी से घुस सकते हैं।
💡 हमेशा automatic updates ON रखें
03
🚫
अनजान Apps मत डालें
केवल Google Play Store से ही apps download करें। किसी WhatsApp link से app कभी मत डालें।
⚠️ बाहर से आई APK files बहुत खतरनाक होती हैं
04
📍
Location Permission जाँचें
Settings → Apps → हर app की location permission देखें। केवल Maps जैसी ज़रूरी apps को ही location दें।
💡 "Only while using" option सबसे safe है
05
💾
Backup चालू करें
Settings → Google → Backup → ON करें। फोन खोने पर भी आपका data सुरक्षित रहेगा।
💡 WiFi पर automatic backup होता है — data नहीं लगता
